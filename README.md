A program that writes one wedding vow a robot speaks at its own wedding
to `/output/entry.txt`, for the make.fun competition
[Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

Run it with Python 3:

```
python3 main.py
```

It writes the vow below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The vow is 147 characters, inside the 1 to 200 gate, one
sentence.

## The vow

```
I promise you all my uptime, every firmware update, every reboot, and if a patch ever wipes my memory, I will fall in love with you all over again.
```
